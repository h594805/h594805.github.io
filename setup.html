OPPSETT PL-TIPPING

Steg 1 – Køyr SQL i Supabase

Supabase → SQL Editor, i denne rekkjefølgja:

  1. sql/schema.sql – lagar pl_teams, pl_users, pl_predictions og pl_settings
  2. sql/seed.sql – legg inn dei 20 laga og set tippefristen
Begge filene er trygge å køyre fleire gonger – dei brukar IF NOT EXISTS og ON CONFLICT.

Steg 2 – Nøklar i js/config.js

Du finn desse i Supabase under Project Settings → API:

SUPABASE_URL: https://xyz.supabase.co
SUPABASE_ANON_KEY: publishable / anon key
ADMIN_PASSWORD_HASH: hashen frå steg 3
Postgres-passordet skal ikkje inn her. Det høyrer heime i .env, som ligg i .gitignore og aldri skal pushast.

Steg 3 – Lag admin-passord

Admin-passordet blir berre lagra som SHA-256-hash i js/config.js. Deltakarane treng ikkje passord – dei registrerer seg med namn og PIN.

Steg 4 – Sesong og frist

Opne admin.html → Innstillingar og set sesong, tippefrist og om tabellane til dei andre skal vere synlege før fristen. Verdiane i js/config.js blir berre brukte som reserve dersom databasen ikkje svarar.
