OPPSETT PL-TIPPING

Steg 1 – Kjør SQL i Supabase

Supabase → SQL Editor, i denne rekkefølgen:

  1. sql/schema.sql – oppretter pl_teams, pl_users, pl_predictions og pl_settings
  2. sql/seed.sql – legger inn de 20 laga og setter tippefristen
Begge filene er trygge å kjøre flere ganger – de bruker IF NOT EXISTS og ON CONFLICT. De gamle VM-tabellene blir ikke rørt.

Steg 2 – Nøkler i js/config.js

Finn disse i Supabase under Project Settings → API:

SUPABASE_URL: https://xyz.supabase.co
SUPABASE_ANON_KEY: anon / public key
ADMIN_PASSWORD_HASH: hashen fra steg 3

Steg 3 – Generer adminpassord

Adminpassordet lagres kun som SHA-256-hash i js/config.js. Deltakerne trenger ikke passord – de registrerer seg med navn og PIN.

Steg 4 – Sesong og frist

Åpne admin.html → Innstillinger og sett sesong, tippefrist og om andres tabeller skal være synlige før fristen. Verdiene i js/config.js brukes bare som reserve hvis databasen ikke svarer.
