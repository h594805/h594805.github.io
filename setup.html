VM 2026 Tipping – konfigurasjonshjelper

Steg 1 – Generer passord-hasher

Skriv inn passordene dine nedenfor for å generere SHA-256-hashene du trenger i js/config.js.

Kopier disse hashene inn i js/config.js:
SITE_PASSWORD_HASH:
ADMIN_PASSWORD_HASH:

Steg 2 – Oppdater js/config.js

Fyll inn disse verdiene i js/config.js:

SUPABASE_URL: Supabase-prosjektets URL (f.eks. https://xyz.supabase.co)
SUPABASE_ANON_KEY: Supabase anon/public key
SITE_PASSWORD_HASH: SHA-256 hash fra steg 1
ADMIN_PASSWORD_HASH: SHA-256 hash fra steg 1
Finn Supabase URL og anon key i Supabase-dashbordet under Project Settings → API.

Steg 3 – Kjør SQL i Supabase

Gå til Supabase → SQL Editor og kjør filene i denne rekkefølgen:

  1. sql/schema.sql – oppretter tabellene
  2. sql/seed.sql – fyller inn alle 48 lag og 104 kamper
⚠️ Kjør bare seed.sql én gang! Hvis du kjører den igjen vil du få duplikat-feil.

Steg 4 – Last opp til GitHub Pages

Etter at config.js er oppdatert:

  1. Pakk hele mappen som .zip
  2. Last opp til GitHub og aktiver GitHub Pages i repository-innstillingene
  3. Pek rekegruppa.no CNAME til dinbruker.github.io/ditt-repo
  4. Del nettstedsadressen og passordet med gruppa!
